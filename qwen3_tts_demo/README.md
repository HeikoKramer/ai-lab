# Qwen3 TTS Demo

A demonstration of the Qwen Text-to-Speech capabilities, specifically focusing on the Qwen2-Audio visual and voice design features.

## Documentation
For technical details and architecture, see [documentation.md](documentation.md).

## Getting Started

### Prerequisites
- Python 3.10+
- GPU with significant VRAM (suggested 24GB+ for 7B models)

### Installation
1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```

2. Run the existing application:
   ```bash
   python app.py
   ```

## Features
- **Voice Design**: Describe the voice you want (e.g., "Female, excited, high pitch") and the model generates it.
- **Direct Synthesis**: Convert text to speech with high fidelity.
